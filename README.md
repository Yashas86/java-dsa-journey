# Java DSA Journey

My structured record of Data Structures and Algorithms practice in Java, primarily through LeetCode.

## Repository structure
- Arrays, Strings, Hashing
- TwoPointers, SlidingWindow, BinarySearch
- LinkedList, Stack, Queue
- Trees, Heap, Backtracking, Graphs
- DynamicProgramming, Greedy, BitManipulation

## File naming
Use `LC001_Two_Sum.java`, `LC206_Reverse_Linked_List.java`.

## For every problem
1. Add the LeetCode number, name, URL and difficulty in the file comments.
2. Explain the approach in your own words.
3. Include time and space complexity.
4. Record mistakes, edge cases and what you learned.
5. Mark honestly whether you solved it independently.
6. Update the companion Google Sheet and schedule a revision.

## Weekly review
Re-solve at least 5 previous problems without looking at the solution. Identify one weak pattern and plan the next week's practice.

Use AI as a tutor/reviewer, not a substitute for understanding. Do not publish premium-only problem statements.
